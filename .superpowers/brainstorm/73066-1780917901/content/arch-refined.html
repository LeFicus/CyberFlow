修正1：爬取频率 & 商品爬取流程

数据源 策略 游标 频率 触发源
站点信息 时间窗口增量 last_updated_at 🕐 每天 1 次 (如 02:00) Quartz Cron

非 Shopify 商品 Sitemap + 选择器解析 — 👤 用户手动触发 用户上传域名+选择器 → 即时下发 MQ

修正2：商品爬取新增配置实体

Shopify 站点配置
用户操作: 在前端输入 Shopify 店铺域名并提交

存储: crawl_site_config 表
domain:  xxx.myshopify.com
type:    shopify
status:  active / paused
created_by: user_id

执行: Python Consumer 读配置 → 请求 /products.json → Pipeline 入库
非 Shopify 站点配置 (选择器)
用户操作: 输入域名 + 配置每个字段的 CSS/XPath 选择器

存储: crawl_site_config + crawl_selector_config 表
domain:  example.com
type:    woo / custom
selectors: {
  "name": ".product-title",
  "price": ".price .amount",
  "description": "#tab-description",
  "images": ".gallery img::attr(src)",
  "sku": ".sku",
  "categories": ".breadcrumb a"
}

执行: Python Consumer → Sitemap 发现 URL → 选择器解析 → Pipeline 入库
