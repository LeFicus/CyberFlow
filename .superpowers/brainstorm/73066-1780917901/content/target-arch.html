核心变化：砍掉了什么，新增了什么

❌ 移除
  • FastAPI (:8000) — 转发层完全消除
  • Redis Broker/Backend — 被 RabbitMQ 替代
  • Celery Worker — 被纯 Python 消费者替代
  • 同步 httpx.Client — 改为 aiohttp
  • 内存 ConcurrentHashMap — 改为 MySQL 持久化
  • CrawlerApiClient (RestTemplate) — 改为 RabbitMQ 发布
✅ 新增
  • RabbitMQ — 消息中枢，解耦调度与执行
  • Quartz Scheduler — 定时增量触发
  • Python asyncio Consumers — 高并发执行器
  • task_history 表 — 持久化任务状态
  • 增量游标表 — 记录每种数据源的最后同步位置
  • 死信队列 (DLX) — 失败任务自动重试/告警
  • Redis — 仅保留 Scrapy SKU 去重
