🔧 选择器模板库 设计

从零散的 JSON 文件升级为系统化的、可复用的选择器模板库

现状 → 目标

❌ 现状：散落 JSON 文件
configs/selectors/
├── magnolia.json
├── sachdevabeauty_com.json
└── test.json
  • 文件散落，无版本管理
  • 无法在前端增删改查
  • 每个站点一个文件，无法复用
  • WooCrawlSpider 通过 config_file 参数手动指定
✅ 目标：选择器模板库
selector_template — 预置模板（系统维护）
crawl_site_config — 站点关联模板 + 覆写
  • Spring Boot 提供模板 CRUD 管理界面
  • 用户注册站点时从模板库选取
  • 支持按站点覆写个别选择器
  • Python Consumer 从 DB 读取配置（不再读文件）

数据模型

表 字段 说明
selector_template id 主键
name模板名，如 "WooCommerce Default" / "Magnolia Theme" / "Shopify Dawn"
platform平台: woo / shopify / magento / custom
title_selector商品标题 XPath/CSS
price_selector价格 XPath/CSS
description_selector描述 XPath/CSS
images_selector图片 XPath/CSS
breadcrumb_links_selector面包屑链接 XPath/CSS
site_map_selectorSitemap 定位 XPath (仅 woo/custom)
crawl_site_config
🆕 增强版		 domain站点域名
typeshopify / woo / custom
template_idFK → selector_template.id（选模板）
selector_overridesJSON 字段，按站点覆写个别选择器
statusactive / paused

使用流程

用户在前端输入域名
→
选择平台类型 (shopify/woo/custom)
→
从模板库选取
如 "WooCommerce Default"
或 "Magnolia Theme"
→
可选：微调个别选择器
存入 selector_overrides (JSON)
→
Spring Boot 下发 MQ
Python Consumer 读配置 → 执行
