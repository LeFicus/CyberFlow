# 商品列表与后台导出

## 使用方式

1. 填写域名、分类、名称、SKU 等条件，点击“查询商品”。高级条件包括价格、采集日期和语言。
2. “已应用”展示实际查询与导出条件，未点击查询的更改不会影响导出。常用条件可保存到当前浏览器，最多 10 个。
3. 使用上一页/下一页浏览，不支持深页码跳转。需要准确总数时单独点击“统计匹配数量”；统计超时不影响浏览和导出。
4. 点击“导出当前结果”，选择 CSV 或 Excel 压缩包、条数上限及每个文件的条数。大批量使用 CSV，Excel 长单元格会截断为 32,767 字符。
5. 在“导出任务”查看已处理行数、排队/打包/失败状态并下载。任务达到上限会明确标记，不能当成全量导出。
6. 删除少量商品可勾选当前页；大批量删除使用“批量删除筛选结果”，按已应用筛选和当前列表快照每次最多删除 500 条，可重复分批执行。

域名与自定义分类使用精确匹配；名称默认开头匹配，可显式改为包含匹配。商品分类包含匹配仍可能扫描大量数据，建议加来源域名/日期范围。价格是原始数值，页面不再假定全部商品为美元。采集日期按数据库中的日期解释。

## 实现与限制

- 新查询接口使用 id 游标，不执行 OFFSET，也不自动执行 COUNT；每页最多 200 行。
- 查询、统计、后台导出共用 ProductFilter 与 SQL 片段，服务器解析用户数据范围；无权访问的用户不返回数据。
- ID 上界固定，可防止后来插入的商品混入当前列表/导出；这不是数据库事务快照，既有数据更新/删除仍可能影响结果。
- 每批读取最多 500 条，单工作线程，最多排队 3 个任务，同一用户最多一个活动任务。单任务最多 500 万行，每文件 1 千至 10 万行；UI 提供 1/5/10 万分片。
- CSV 使用 UTF-8 BOM、标准引号转义，并将潜在公式字段作为文本；Excel 文本写入且所有字段均受单元格长度保护。
- 文件保留 24 小时，约每 10 分钟清理；最多 100 个未过期任务，低磁盘空间会阻止新导出。4GB 为压缩文件的软保护上限，打包阶段/单批次可能临时超过。
- 下载通过登录用户申请 2 分钟有效的一次性票据，再由浏览器直接下载；不把完整 ZIP 缓存到前端内存。票据使用前再次校验账号及数据范围。
- 元数据与文件保存在一个实例的磁盘卷；重启后已完成任务可继续下载，中断任务标记失败并可重新创建。多实例部署需改用共享任务库、队列和对象存储，本实现不保证跨实例调度。
- 页面保留“删除所选”，不再暴露同步“清空当前筛选”，避免对百万行数据执行大事务，或新筛选条件在旧清空接口中失效。旧接口保留兼容。

## 部署

- 先执行 `script/migrations/20260827_product_workspace_indexes.sql`，为域名/分类/角色/SKU 的 ID 游标访问补充索引。脚本可重复执行，在线 DDL 仍会产生 CPU/IO 负载，大库请在低峰运行。
- Docker Compose 配置 `CYBERFLOW_PRODUCT_EXPORT_DIRECTORY=/app/product-exports` 与 `product_exports` 持久化卷。
- 本地非 Docker 默认目录为 `.data/product-exports`，已加入 gitignore。
- 重建后台后刷新前端。现有商品查看权限用于列表与导出，无需新增角色授权。

## 验证（2026-08-27）

- 前端测试 15 项通过；后端普通测试 30 项通过。
- 独立 MySQL 测试使用会话级临时表合成 100 万行，不改动正式商品表。断言空数据范围不可见、过滤统计 8,000 条与分批读取数量一致。
- 本机 `EXPLAIN ANALYZE`：跳过前 900,000 行后取 50 条约 528ms；等价主键游标约 0.151ms；带域名游标约 0.826ms。仅为合成数据和本机环境的单次查询结果，不能推广为生产 SLA。
- 实际 Hitachi 名称开头筛选统计 188 条，后台 CSV ZIP 含 188 行数据、12 列，逐行检查名称均匹配。后台重启后任务与文件仍可用，浏览器下载请求已由服务端确认传输 9,113 字节。

测试命令：

```sh
cd frontend && npm test && npm run build
cd ../backend-admin && mvn test
# 显式执行数据库压力测试；临时表生成会占用额外数据库资源
CYBERFLOW_PRODUCT_DB_TEST=1 mvn -Dtest=ProductQueryDatabaseTest test
```

数据库测试可用 `CYBERFLOW_TEST_DB_URL`、`CYBERFLOW_TEST_DB_USER`、`CYBERFLOW_TEST_DB_PASSWORD` 指定连接。切勿在高峰生产实例执行压力测试。
